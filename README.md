# 取景地打卡模拟器 qujing-daka

国庆假期只有 3 天、预算有限，怎么跟着"国庆档电影"把取景地打卡玩出花？

## 热点来源声明

致敬 2026 年国庆真实社会现象——**"从看客变主角"**：国庆档电影取景地成为出游新选择，
乐陵影视城、石炭井文旅小镇、哈尔滨、佛山江门等地因影视热带动旅游热。
本项目只借用"跟着电影去旅行"这一概念做善意娱乐创作。

**本项目中的 6 部电影（《雪域缉凶》《欢喜岭南》《人间烟火气》《水乡精灵》
《星际戈壁》《海风情书》）与 6 个取景地（冰雪之城、岭南古镇、西北影视小镇、
江南水乡、戈壁影视城、海滨老街）全部为虚构**，与任何真实影片、真实地点无关。

## 玩法

- 你有 **3 天假期 + 6000 元预算**。
- 6 部虚构电影 × 取景地，每个取景地有：路费、门票、**出片率**（拍照好看度）、
  **人从众指数**（国庆人越多体验越差）。
- 每天选 **1–2 个**取景地打卡，预算花完或 3 天结束即结算。
- 打卡随机触发事件：
  - ★ **偶遇剧组路透**：快乐暴击（快乐+20、出片+10）
  - **景区"电影同款套餐"被宰**：预算-300、快乐-10
  - **NPC"戏中人"换装体验**：出片+15、快乐+10
- 结算分 = 出片总分 − 0.3×人从众 − 0.2×快乐加成，按结果授予称号：
  - **取景地之王**（打卡 ≥5 且总分 ≥300）
  - **朋友圈摄影大赛冠军**（打卡 ≥3 且平均出片 ≥75）
  - **人从众受害者**（人从众惩罚 ≥80 或总分 <100）
  - **快乐打卡游客**（其他）

## 运行

```bash
python3 -m qujing_daka                      # 交互模式（需要终端）
python3 -m qujing_daka --auto               # AI 自动演示（性价比贪心规划）
python3 -m qujing_daka --auto --games 10 --seed 42
python3 -m qujing_daka --auto --games 1 --seed 42 --verbose   # 每日战报
```

纯 Python 标准库（argparse / random / sys / select），Python 3.10+。

## 诚实局限

- 数值（路费/门票/出片率/人从众）为拍脑袋设定，平衡性未经大规模仿真
- AI 规划只是按性价比的固定贪心策略，不是真正的行程优化
- 事件纯随机触发，没有"剧组真的在拍"的任何真实逻辑
- 纯文本界面，无图形、无存档；倒计时输入用 `select` 实现，仅 Unix 终端有效
- 文案为虚构池，多玩几局会眼熟；Python 3.10+，纯标准库
